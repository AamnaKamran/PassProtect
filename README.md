# 🔐 PassProtect

**PassProtect** is a basic password manager built with Python, Tkinter, and SQLite. It allows users to save and view credentials for different apps or websites in a clean and easy-to-use interface.

## 🧰 Features

- Login and account creation
- Save credentials (App Name, Username, Email, Password)
- View all saved credentials with a scrollable list
- Local database storage using SQLite

## 📂 Files Overview

- `main.py` – GUI and app logic
- `db.py` – Database setup and helper functions
- `padlock.png` – Logo image (place in the same folder)
- `user_data.db` – Automatically generated SQLite database
